# Code of Conduct

Prompt2Music is an open-source project and aims to provide a welcoming, professional environment for everyone who participates.

## Expected behavior

Be respectful and constructive. Discuss ideas and code rather than attacking people. Give useful feedback, assume good intent when reasonable, and respect differences in experience and perspective.

## Unacceptable behavior

Harassment, threats, discriminatory language, personal attacks, deliberate disruption, doxxing, or publishing another person's private information without permission are not acceptable.

## Scope

This code of conduct applies to project spaces including issues, pull requests, discussions, reviews, and other community interactions representing Prompt2Music.

## Enforcement

Project maintainers may edit or remove contributions that violate these expectations and may restrict participation when necessary to protect the community.

For conduct concerns, contact the repository owner privately through an appropriate GitHub contact channel rather than opening a public issue containing sensitive information.
